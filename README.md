# Conhecimento Vivo — Landing conceitual V1

Protótipo funcional de landing page para startup de IA proprietária, usando HTML, CSS e JavaScript sem dependências de build.

## Executar
Abra `index.html` no navegador ou execute `python3 -m http.server 8000` na pasta e visite http://localhost:8000.

## Publicar gratuitamente
1. Crie um repositório no GitHub e envie `index.html`, `styles.css` e `script.js`.
2. No Cloudflare Pages, escolha **Connect to Git** e selecione o repositório.
3. Escolha framework **None** (sem build command), diretório de saída `/` (raiz).
4. Publique no subdomínio gratuito *.pages.dev, depois adicione domínio próprio se desejar.

## Antes de publicar
- Substituir o nome provisório **Conhecimento/Vivo** pela marca definitiva.
- Substituir `contato@exemplo.com` por e-mail real ou URL de agendamento.
- Validar textos comerciais, políticas de privacidade e identidade visual.
- Adicionar analytics com consentimento apropriado caso colete dados pessoais.
- O diagnóstico roda exclusivamente no navegador e **não coleta respostas**.
- Testar contraste, navegadores e usabilidade com usuários reais.

## Características
Responsivo, animação canvas leve, fallback para reduced motion, questionário interativo local, metadados SEO básicos. Fontes Google Fonts (com fallback local).
